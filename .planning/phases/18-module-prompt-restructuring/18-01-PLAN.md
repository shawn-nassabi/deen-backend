<objective>
Replace all ChatPromptTemplate.from_messages() constructions in core/prompt_templates.py and all 6 modules/fiqh/ files with builder functions that return list[BaseMessage] using make_cached_system_message() (static) or plain SystemMessage (dynamic).

Purpose: ChatPromptTemplate.format_messages() strips cache_control from content blocks (GitHub #26701), so prompt caching is silently broken in these modules. This plan eliminates the ChatPromptTemplate pattern at its source.

Output:
- core/prompt_templates.py: 6 ChatPromptTemplate objects replaced with builder functions; 2 enhancer templates left as-is with exclusion comment
- modules/fiqh/{classifier,refiner,sea,generator,decomposer,filter}.py: each gets _build_messages() private function replacing _prompt module-level variable
</objective>
