**Current implementation (the block to replace):**
```python
from fastapi.responses import JSONResponse
from fastapi.requests import Request
import traceback

@app.middleware("http")
async def catch_exceptions_mw(request: Request, call_next):
    try:
        return await call_next(request)
    except Exception as e:
        tb = traceback.format_exc()
        print("\n===== SERVER EXCEPTION =====\n", tb, "\n============================\n")
        sentry_sdk.capture_exception(e)
        return JSONResponse(status_code=500, content={"detail": "internal_error", "error": str(e)})
```

**Replacement:**
```python
import logging
from fastapi.responses import JSONResponse
from fastapi.requests import Request

logger = logging.getLogger(__name__)

@app.middleware("http")
async def catch_exceptions_mw(request: Request, call_next):
    try:
        return await call_next(request)
    except Exception as e:
        logger.error(
            "Unhandled exception",
            exc_info=True,
            extra={"path": str(request.url.path)},
        )
        if SENTRY_ENABLED:
            return JSONResponse(status_code=500, content={"detail": "internal_error"})
        return JSONResponse(
            status_code=500,
            content={"detail": "internal_error", "error": str(e)},
        )
```

Key constraints:
- `import traceback` MUST be removed — `exc_info=True` on the logger call handles stack trace capture via the logging system. No manual `traceback.format_exc()` needed.
- `sentry_sdk.capture_exception(e)` MUST be removed — `LoggingIntegration(event_level=ERROR)` auto-captures any `logger.error(exc_info=True)` call as a Sentry event. Keeping both would create duplicate events in Sentry.
- `print(...)` MUST be removed — D-10 replaces it with `logger.error()`.
- `logger = logging.getLogger(__name__)` instantiation goes above the `@app.middleware` decorator, NOT inside the function. Module-level logger is the project convention (see api/hikmah.py lines 28-29).
- `SENTRY_ENABLED` is already imported at the top of main.py from `from core.sentry import SENTRY_ENABLED` (Task 1). No re-import needed.
- `from fastapi.responses import JSONResponse` and `from fastapi.requests import Request` may already be imported — check before adding duplicate imports.
- If `sentry_sdk` was still imported at the module level, verify it is now unused and remove the import.
  </action>
