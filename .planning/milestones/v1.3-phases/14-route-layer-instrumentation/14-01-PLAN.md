```python
async def references_pipeline(
    request: ReferenceRequest,
    credentials: JWTAuthorizationCredentials = Depends(auth),
    sect: str = Query("both", enum=["sunni", "shia", "both"]),
    limit: int = Query(10, ge=1, le=50, description="Number of references to fetch (1-50)"),

    corr_id = correlation_id_ctx.get()
    bind_sentry_scope(corr_id, "/references")

    try:

            extra={"correlation_id": corr_id, "endpoint": "/references"},
        )
        return {"response": results}

        logger.error(
            "References pipeline error",
            exc_info=True,
            extra={"correlation_id": corr_id, "endpoint": "/references"},
        )
        raise HTTPException(status_code=500, detail="internal_error")
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→/references | User-controlled query string crosses into pipeline; exception messages previously leaked back across this boundary (REF-02) |
| log sink→Sentry | extra={} fields from route handlers flow to Sentry Logs; log injection risk if user text included |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Information Disclosure | api/reference.py except block | mitigate | REF-02 fix: replace `detail=f"Internal Server Error: {str(e)}"` with `detail="internal_error"`. Exception text logged via logger.error(exc_info=True) to Sentry only, never returned to client. |
| T-14-02 | Information Disclosure | api/hikmah.py + api/reference.py extra={} | accept | extra={} fields are safe: correlation_id (UUID), lesson_content_id (int), lesson_name (opaque string), error (server-side exception — goes to Sentry, not client). No user_query text in any extra={}. |
| T-14-03 | Tampering | correlation_id in extra={} | accept | correlation_id is generated server-side by CorrelationIdMiddleware (Phase 13) — client cannot inject a fake value. ContextVar is set once per request before route handler runs. |
</threat_model>
